# livito-instagram

Ablage für den Instagram-Account @dielivitomethode.

- `media/karussell/` Folien der Karussells (1080 × 1350, PNG)
- `media/reels/` Reels (1080 × 1920, MP4) und Titelbilder
- `system/` Vorlagen, Skripte, Schriften und Klangbetten, aus denen die Beiträge entstehen

Die Dateien in `media/` werden von Metricool über ihre öffentliche Adresse abgeholt.
Nichts erscheint ohne Freigabe.
